Questions, answered

Do I need to install anything?

No. ClipForge runs entirely in your browser — Chrome, Edge, Firefox or Safari. Nothing to download, nothing to update.

Are my videos uploaded to a server?

No. Imported files are read locally with the browser File API. Editing and exporting happen on your own device. Only if you choose “Save online” does ClipForge store a project (and the media you selected) on your own server.

Is there a watermark or a paywall?

There is no watermark and no signup. The whole editor is open — timeline, filters, titles, audio and export.

What can I export?

WebM (VP9/VP8 + Opus) and, where the browser supports it, MP4 (H.264 + AAC). Pick 480p, 720p or 1080p and a bitrate, then download the file.

Can I come back to a project later?

Yes — save the project file (it’s small JSON) and reopen it any time, or save it to this server so it shows up under “My projects”.

Is export really instant?

Export is real-time: the browser plays your timeline once while recording it, so a 30-second video takes about 30 seconds. No queue and no upload, so it still beats waiting on a cloud render.
